Lecture 1 - Introduction and Logistics

2026-08-03 / CMU 10-414: Deep Learning Systems / #CMU , #CMU 10-414 , #DeepLearning / 阅读 -

本文根据 原视频 整理，内容来源：UP 主 Mindofuture。

课程概览与学习动机

这门课程的全称是“深度学习系统：算法与实现”，由卡内基梅隆大学的 Zico Kolter 与陈天奇（Tianqi Chen）两位老师联合授课。本次讲座是课程的第一讲，主要承担两个任务：解释为什么要学习深度学习系统，以及介绍课程的具体安排。与后续深入讲解方法、数学推导和代码的讲座不同，这一讲侧重背景与框架。

讲师背景与课程定位

Zico Kolter 在深度学习领域有深厚的积累，他的研究涉及对抗鲁棒性、隐式层等方向，并且是 PyTorch 早期的贡献者之一。陈天奇则是机器学习系统领域极具影响力的研究者，主导或深度参与了 XGBoost、MXNet、TVM 等一系列关键系统的开发。两位老师均在卡内基梅隆大学任教，这门课原本也是面向 CMU 在校生开设的线下课程，现在将所有材料作为公开课免费发布。

影响力与系统驱动

在讨论深度学习系统之前，有必要先回顾深度学习本身已经展现出的能力。课程列举了几个里程碑式的案例，不是为了做历史考证或争夺“首创”之名，而是为了直观呈现这个领域在短时间内取得的惊人进展。

2012 年的 AlexNet 架构在 ImageNet 图像分类挑战赛上大幅超越了当时的传统计算机视觉方法，被普遍视为深度学习在可用性和能力上的一个重要转折点。2016 年的 AlphaGo 系统击败了世界顶尖围棋选手——围棋长期被视为对计算机博弈的终极挑战，因为每一步的可能走法数量远非国际象棋可比，传统搜索技术难以应对。深度学习的介入让这一突破比多数人预想的来得快得多。

生成模型的发展同样令人印象深刻。StyleGAN 系统生成的人脸图像刚出现时，许多人以为那是训练集的真实照片被拿来开玩笑，但那些面孔确实完全由网络生成。仅仅四五年时间，生成逼真的人像已经从不可思议变成司空见惯。GPT-3 则展示了另一条路径：它本质上只做一件事——根据之前的所有 token 预测下一个 token，然后把这个 token 追加到文本后面，再预测下一个。这个看似简单的过程却能产生极其复杂且连贯的长文本。课程中甚至让 GPT-3 为这门课写了一份总结，结果它给出了一份相当合理的通用深度学习课程描述（尽管对本课程来说并不准确，因为它提到了无监督学习和强化学习，而这门课并不涵盖这些内容）。

AlphaFold 系列系统则根据由基因编码的氨基酸序列预测蛋白质的三维结构，这是一个困扰生物学界数十年的难题。在蛋白质折叠预测竞赛中，AlphaFold 在四年内将预测质量和准确性提升到了堪称科学突破的水平，以至于在某些受限场景下，这个问题可以说已经被有效解决。最后，Stable Diffusion 系统在 2022 年秋天发布——恰好与这门公开课的视频公告同一天。它能根据文本提示生成高度逼真的画作，其背后承接了 DALL·E 2、DALL·E 以及更早的一系列研究工作。

这些案例的共同点在于，它们的实现都离不开深度学习系统框架的支持。一个直观的证据来自谷歌趋势：图中“深度学习”的关注度在 Keras、TensorFlow 和 PyTorch 等易用框架发布后快速攀升，其时间关联比 AlexNet 发布后的变化更显著。讲师据此提出，易用框架的涌现是深度学习得以大规模普及的关键驱动力之一；这是一种由趋势图支持的解释，而不是严格的因果证明。课程中又用一个代码量对比来强化这一点：陈天奇在早期做深度学习项目时，需要手写约 44,000 行代码、耗时约六个月，才能完成一个强大的图像分类卷积架构；而在今天的框架下，同类任务只需大约 100 行代码、数小时就能实现。这种数量级的差异，直接反映了系统层面对开发者效率的重塑。

学习系统的理由

既然框架已经如此易用，为什么还要花时间去学它内部的原理？课程给出了三个核心动机。

第一，构建或贡献框架的需求。你可能需要为新的硬件平台、新的算法范式开发专门的深度学习工具，或者向现有框架贡献代码。这些事情都要求你理解系统内部是如何运作的。

第二，写出更高效、可扩展模型的“超能力”。即使你只是框架的使用者，深入理解底层机制也能帮助你避开性能陷阱，写出更高效、更可扩展的模型。这种能力在日常工程实践中直接转化为更快的迭代速度和更低的资源消耗。

第三，核心算法在实现上的极简与神奇之处。自动微分、梯度优化等深度学习系统的核心算法，在数学原理上非常简洁，但在工程实现上却蕴含着精巧的设计思想。理解这些会让人对整个系统产生一种通透的掌控感。

课程架构与学习组件

这门课的目标是让你理解现代深度学习系统的内部运作方式，包括自动微分、基本神经网络架构、优化方法，以及在 GPU 等硬件上实现高效运算的技术。为了巩固这些理解，课程设计了一个贯穿始终的实践主线：从零开始构建一个名为 Needle（Necessary Elements of Deep Learning）的深度学习库。Needle 在功能上类似于一个精简版 PyTorch，你将在作业中逐步实现它的各个组成部分以及多种常见架构。

编程作业与 Needle

作业是这门课的核心。通过四个递进式的编程作业，你将逐步搭建起 Needle 库的完整骨架，涵盖自动微分、神经网络模块、CPU 与 GPU 线性代数后端，以及常见架构的实现。这个过程迫使你直面系统设计中的真实问题，而不是停留在调用 API 的层面。

在深入课程细节之前，还需要说明这门课是如何组织的。整个学习过程由四个核心组件构成，它们共同支撑起从理论到实践的完整路径。

视频讲座

讲座的形式会混合使用幻灯片、数学推导和现场编程。视频采用一次性录制、不做后期剪辑的方式，保留了一种接近直播课堂的真实感。所有视频内容都会在 YouTube 等平台上免费公开，无论是注册学生还是自学者都可以随时访问。

作业是整个课程最核心的部分。通过四个递进式的编程任务，学习者会从零开始构建名为 Needle 的深度学习库。Needle 这个名字来自“深度学习的必要元素”（Necessary Elements of Deep Learning）。四个作业分别覆盖自动微分、神经网络模块化设计、CPU 和 GPU 上的线性代数后端实现，以及常见神经网络架构的搭建。完成这一系列作业之后，学习者将拥有一个功能基本完备、类似于简化版 PyTorch 的深度学习框架。

期末项目

期末项目以小组形式进行，目标不是简单地用现有框架训练一个模型，而是为 Needle 库开发新的功能模块。例如，为新的硬件后端提供加速支持，或者实现算子融合等优化技术。从工作量和技术深度来看，期末项目相当于第五个作业。

课程论坛与社区

注册学生可以通过课程论坛进行互动、提问和相互帮助。论坛有一个鼓励机制：如果你觉得某个问题很有价值，可以为它点赞，这样讲师更容易注意到并优先回答。同时，课程明确禁止在论坛上分享完整的作业解决方案，这是为了保障每个人都能获得完整的动手学习体验。

课程产出与评估方式

在了解课程结构之后，自然会关心完成这门课后能获得什么，以及如何评估学习成果。

学习目标与能力达成

学完这门课之后，学习者应当能够理解现代深度学习库的内部工作原理，并且具备从零实现多层感知机、卷积神经网络、循环神经网络、LSTM 以及 Transformer 等主流架构的能力。最终，学习者会拥有一个自己开发的、具备自动微分和 GPU 加速能力的中等规模深度学习库。

自动评分系统与结业认证

课程的作业评估采用一套独特的本地自动评分机制：学习者不需要将代码上传到远程服务器执行，而是在本地运行代码并提交答案，由系统与参考答案核对。这种方式减少了本地环境与评分服务器环境不一致所带来的问题，让评分过程更加顺畅。如果作业平均分达到 80% 或以上，并且提交了期末项目，就可以获得一份个性化的结业证书；该公开课证书不等同于 CMU 学分。

能够如此快速地迭代，是深度学习系统带来的一项极其重要的推动力。人们通常认为深度学习模型训练慢、开发慢，尤其是大型模型；但在这些系统的支持下，开发迭代已经可以非常快。不过，这仍然没有回答最初的问题：既然深度学习系统已经很好用，直接用 PyTorch、TensorFlow 或 JAX 不就行了，为什么还要上一门介绍其内部运作方式的课？

对此，有三个核心理由。

第一个理由或许最显而易见：如果想构建深度学习系统，就应当理解它们。尽管 TensorFlow 和 PyTorch 这样的库似乎已经成为某种行业标准，但深度学习系统这个领域实际上仍在快速变化。课程录制前几年，JAX 在大量深度学习研究中兴起，就是一个例证。从某种意义上说，这个领域还没有走到终点。在开发新系统方面，还有很多工作要做，也许是更专用的系统，也许是专注于某个不同领域或不同深度学习范式的系统。主流框架大多开放了源代码；理解其内部机制后，学习者便有可能阅读源代码并参与贡献。这门课与后续实践将为此打下基础。

第二个理由，是讲师会向该领域的从业者最着重强调的：理解深度学习系统内部的工作原理，能让你更高效、更有效地使用它们。如果你想构建可扩展的模型、高效的模型、执行速度快或能充分利用 GPU 的模型，你确实需要理解这些系统在底层是如何工作的。真正被执行的是什么？它们是如何将你对网络架构的高层次描述，转化为真正在硬件上执行、然后训练、对该系统进行微分、调整参数等一系列操作的？理解其工作原理，实际上能让你写出更高效、更有效的代码。如果你正在做深度学习研究，这一点尤其正确，特别是当你在开发新类型的层、新架构、新结构时。理解了这些系统背后的逻辑和机制，将会大有裨益。讲师一直把理解深度学习系统称为一种“超能力”，它能让你实现研究目标，即使你的研究目标不是构建系统，也能让你更高效地实现它们。这可能是大多数学习者可以并且应该选修这门课的主要原因。

第三个理由则更加本质：深度学习系统真的非常酷。这些系统之所以如此有趣，原因其实很简单。尽管 PyTorch 和 TensorFlow 如今都有数百万行代码，看似复杂，但深度学习系统背后那些功能相当强大的核心底层算法，是极其简单的。每一个深度学习架构背后的核心算法，从算法层面来看，本质上都基于自动微分和基于梯度的优化，至少从数学角度看是这样。这两个算法实际上构成了这一切的基础。而在实现层面，它们本质上构建于高效的线性代数之上，尤其是在 GPU 系统上进行高效的矩阵乘法。

这和操作系统形成了鲜明对比。如果你想构建一个操作系统，你真的需要写相当多的代码，即便如此，也只能构建一个非常基础的系统。但一个相当不错的深度学习库，如果代码写得非常紧凑，可能用不到 2000 行代码就能完成。它能在 GPU 上运行，能进行自动微分，能实现卷积、卷积网络、循环网络、Transformer 等操作，所有这些都能做到。你几乎不需要多少代码就能实现，因为这些系统背后的核心思想很简单。

而且它们也确实有点神奇。讲师回忆起在从事深度学习工作之前，在传统机器学习的环境中成长时，所有的梯度都是手动推导的。当你推导某个新模型时，主要的精力就是花在手动写出一堆梯度上。第一次构建自动微分库时，讲师意识到可以构建某个复杂的表达式，求其梯度，然后构建一个关于其梯度的更复杂的表达式，并对那个东西进行微分——尽管事实上手动推导出那个梯度都相当困难，可能最终能推导出来，但会花费很长时间，然而却可以写一些代码来完成。这真的非常酷，这是每个从事深度学习工作的人都应该拥有的体验。

接下来是课程及后勤安排。讲师 Zico Kolter 是卡内基梅隆大学的教员，从 2012 年起就在这里工作。除了学术工作，他还在工业界有不少经历，曾在 C3.ai 工作，并在课程录制时担任博世人工智能中心的 AI 研究首席科学家。

Kolter 老师的学术研究侧重于许多新技术和新方法，主要集中在深度学习领域。他在对抗鲁棒性方面做了很多工作，特别是在对抗攻击的认证和可证明防御方面。他还在被称为“隐式层”的领域做了大量工作——这些层不是通过堆叠传统操作形成的，而是通过实际求解一个更复杂的算子（比如一个优化问题或一个不动点方程）来形成的，并且你会解析地对这些进行微分。根据目前的计划，如果时间允许，课程的最后将安排一节关于隐式层的讲座，当然会用课程自己的框架来实现。Kolter 老师也是 PyTorch 的早期使用者，不过他很快补充说，这跟陈天奇老师所做的系统工作比起来简直微不足道。

陈天奇老师的研究领域则偏向机器学习系统本身。他是 OctoML 的联合创始人之一，这家公司为 TVM 库提供大量支持与开发。但在这些头衔之外，真正值得展开的是他在整个机器学习系统领域留下的印记。课程讲师 Zico Kolter 在介绍他时常用一个说法：在这个领域，真正重量级的玩家有三个——谷歌，发布了 TensorFlow、JAX 等一系列库；Meta（当时的 Facebook），有 PyTorch 和 Prophet 等时间序列工具；然后就是陈天奇，以个人身份做出了同等影响力的贡献。

他是 XGBoost 的最初开发者。XGBoost 至今仍是表格数据领域使用最广泛的梯度提升库之一，在 Kaggle 竞赛和工业界都占据着核心地位。他也是 MXNet 的首席开发者，MXNet 是和 PyTorch、TensorFlow 同期的深度学习框架。近年来，他还是 Apache TVM 的创始开发者和核心贡献者之一，TVM 专注于深度学习编译器和硬件加速优化。这三项工作分别覆盖了传统机器学习、深度学习框架和底层编译优化，横跨了机器学习系统的多个抽象层次。

在进入课程具体内容之前，有一个重要的免责声明需要说明。这是这门课第一次以在线形式提供，很多材料——尤其是作业，这是课程最复杂的部分——正在从之前的版本中修改调整。即使是 CMU 校内的版本也在同步修改，相当于在线课程的同学会参与这些内容的 Beta 测试。因此，课程内容和作业中不可避免地会出现 bug，后勤安排上也可能有小问题。这门课是免费的，讲师团队自己整理所有材料，他们希望大家理解这一点，也提前为此致歉。他们会尽力修复问题，必要时也会延长作业截止日期。某种意义上，成为第一批在线课程的学生，也就意味着成为这门课的 Beta 测试者。

接下来是学习目标。如果坚持学完整门课，完成所有作业并做完期末项目，到课程结束时，你将理解现代深度学习库的基本运作原理。这包括从算法角度理解自动微分和基于梯度的优化等概念。你将能够真正从零开始实现几种标准深度学习架构——多层感知机、卷积网络、RNN 或 LSTM 等循环神经网络变体，以及 Transformer。所谓“从零开始”，指的是在没有 PyTorch 或 TensorFlow 支持的情况下，仅使用原始 Python 来实现这些网络。

你还将理解硬件加速在底层是如何工作的，并能够开发自己的高效代码。当然，需要明确的是，你写的代码不会达到 PyTorch 或 TensorFlow 那样的顶尖效率。在极致优化所能达到的性能和你用几十行代码能做到的事情之间，仍然存在巨大差距。但你将能够创建出可以在合理的中等规模数据上运行的库，比如 CIFAR 这样的数据集，以及相应规模的网络和架构。这些库将完全从零开始构建，运行在 GPU 上，具备自动微分功能和优秀的优化器。

课程网站是 dlsyscourse.org，上面有所有相关信息，也会发布全部讲座。网站上有主题日程表，可以查看将要学习的内容。需要留意的是，截图所列日程表是 CMU 校内版本，大约比在线版本早两周。但在线讲座视频的发布日期和链接也会在可用时公布，整体结构将与 CMU 主课程保持一致。实际上，只有第一讲的幻灯片因为后勤安排不同而略有差异，其余日程安排两个版本保持一致。

日程表涵盖了机器学习复习与背景知识、自动微分、各种架构等内容。很多讲座被分为两类：算法讲座和实现讲座。算法讲座涵盖的是用于解决深度学习中某项任务的方法论、算法或技术；实现讲座则是在现场编程中实际实现其中的某些部分，带你了解这些内容在实践中是如何完成的。

关于先修知识，为了从这门课中获得最大收获，最好具备一些合理的基础。如果某些条件暂时不满足但确实充满热情，也可以在课程进行的同时补上这些知识，只是需要付出额外的努力。具体来说，你应该有一些系统编程的背景——这意味着你了解 C++ 编程，知道如何编译东西，不仅是运行 Python 脚本，而是真正编译出能在硬件上原生运行的可执行代码。线性代数是最大的要求。你应该熟悉向量和矩阵的表示法，后续讲座会大量涉及矩阵和向量相乘的运算，以及对这些运算求梯度或导数。微积分方面，真的就只是求导数，基本不涉及积分。概率论里或许有些积分，但在深度学习中很少用到。关键是，当你看到梯度符号时，应该知道它们意味着什么。课程可以提供一些复习材料或背景知识链接，但如果这些概念对你来说完全是全新的，那跟上课程会面临不小的挑战。

先修要求与预备

必备技能清单

在数学方面，课程不要求学习者完成复杂的理论证明，这毕竟是一门系统课程；但需要熟悉一些基本的数学推导方法，例如如何推导梯度。这些技能在后续理解自动微分和反向传播时会反复用到。

编程背景方面，需要同时具备 Python 和 C++ 的开发经验。一个常见的问题是：到底需要多少 C++ 背景？答案是不需要太多。课程不会依赖 C++ 的高级特性，也不要求掌握 C++11、C++20 等现代标准中的复杂功能或 unique_ptr 一类工具。用讲师略带玩笑的说法，课程使用的基本上是“C 加上一些类”，所以只需要较少的 C 或 C++ 经验。

但有一个具体的底线：如果给你一个用 C++ 写矩阵乘法调用的模板——这个模板会接收一堆 float 指针、const float 指针，以及矩阵的尺寸等参数，那些指针指向矩阵中原始的底层数据——你应该知道如何快速地写出一个矩阵乘法例程，将两个矩阵相乘。更重要的是，当你在 C++ 中搞乱索引时（因为没有安全索引，这种情况一定会发生），程序会发生段错误，你必须知道如何调试它。无论是通过调试器，还是像 Zico 老师那样主要通过 printf 语句来定位问题，当代码发生段错误时，你应该有能力找出问题并修复它。

Python 方面，你需要熟悉 Python 中的类设计等概念，因为整个库的大部分结构都将用 Python 实现。C++ 的角色是为底层操作提供高性能后端。

可选技能与自我评估

关于 CUDA 编程，不需要提前了解。课程会涵盖所有需要知道的 GPU 编程内容，但你需要理解基本的 C++ 编程作为前提。

最后，你确实需要有机器学习的先前经验。如果机器学习对你来说还比较陌生，建议先上一门机器学习课程再来学习这门课。如果你已经熟悉机器学习，甚至已经很大程度上熟悉深度学习，再通过这门课来深入理解这些东西实际上是如何工作的，收获会大得多。

如果对自己的背景是否匹配课程要求感到不确定，Zico 老师的建议是：先看前三节课（不包括当前这节课），并且看看作业零。作业零会在正式开课两天后发布，它的本质是复习一些传统编写方式的基本思想。具体来说，你将实现一个 softmax 回归和一个简单的两层神经网络，使用的是手动反向传播的方式。你应该对这类内容感到熟悉——以前见过，也许通过一点复习就能相对快速地完成。作业零中还有一个部分需要你用 C 写，用 C++ 后端实现。如果这些对你来说非常具有挑战性，那么你可能应该在上这门课之前先补充一些其他材料。但如果所有这些事情都相当简单，或者在稍微复习后就确实能变得简单，那么这门课很可能适合你的水平。

这门课有四个主要元素：视频讲座、基于编程的作业、分组完成的期末项目，以及课程论坛上的互动。为了获得课程的全部价值，参与所有这些环节非常重要。每一个组成部分都对真正理解材料起着至关重要的作用。即使讲座没有直接用于作业，它们仍然非常重要；即使论坛在某种意义上说是可选的，与其他参加课程的学生进行互动，对于尽可能从中获得最大收获是非常有价值的。

需要强调的是，这个在线公开课程实际上是独立于 CMU 版本提供的。所以，即使你通过了并且成绩很好，也不能获得 CMU 学分或类似的东西。但课程会为完成作业、平均分达到 80% 或更高，并提交了期末项目的每个人提供一份个性化的课程结业证书。课程团队会想办法使其正式化，可能会发布在网站上或其他地方，让你可以有一个指向它的官方链接。这份证书在某种意义上证明你已经参加并完成了这门课程，即使是在线形式。因为这需要付出很多努力，课程团队确实想确保你有一些东西可以展示，有一些记录表明你已经成功完成了这门课。

视频讲座基本上就是当前正在观看的这种格式。它们是讲座的现场录制，包含幻灯片演示，但大多数讲座不会仅仅是幻灯片——事实上，这节课可能是唯一一节只有幻灯片的讲座。其余的讲座还会有数学笔记、推导，并且在很多情况下，会有现场编码来说明一些想法。所有讲座的视频都将发布到 YouTube 或其他视频网站，课程团队会尽量让它们在几个不同的视频网站上可用，以便全球访问。

根据课程时间表，视频将对所有人开放。因为它们在 YouTube 上，任何人都可以观看，不需要正式注册课程。如果你已经坚持看到讲座的这里，你可能已经能看出来：这些讲座是一次性录制的，不会做很多剪辑。基本上，课程团队是现场录制这些内容，以最少的剪辑剪掉开头、结尾，或者如果真出了什么大问题才剪掉中间部分。讲座大多会一次性完成，并且包含真实讲座中发生的所有小插曲。所以这算是在线版本，但仍然是某种直播——可以把它们想象成讲座的直播流。

如果要指出这门课最重要的组成部分，那就是编程作业。除了用于复习与自我评估的作业零之外，还有作业一到作业四这四个正式作业。这四个作业带学习者经历构建 Needle 库（Necessary Elements of Deep Learning，深度学习必要元素）不同部分的过程——这是一个最小化的 Python 深度学习框架。

具体来说，学习者将首先为 Needle 开发一个自动微分框架，然后使用它构建一个简单的神经网络库，包含神经网络模块、优化技术、数据加载等组件；接着在 CPU 和 GPU 系统上实现线性代数后端；最后在第四个作业中，使用这些组件实现一系列常见架构，例如卷积网络、循环网络，可能还包括 Transformer。

每个作业都建立在之前的作业之上，你必须按顺序完成它们。必须先完成第一个作业，然后才能做后面的，因为它们彼此依赖。这个构建库的过程真的是这门课的核心组成部分，也是你通过它学到最多东西的方式。任何人都可以观看讲座视频，但为了提交作业，你确实需要正式注册这门课。如果你只是在 YouTube 上观看视频并且还没有注册，那么如果你想提交作业——这真的是你学习这些材料的方式——就应该注册课程，你会得到一个账户来向自动评分系统提交作业。

作业完全是基于编码的。作业中没有推导题，没有理论问题——或者说，任何推导都是隐式的，因为之后你必须把它编码出来，以知道它是否真的有效。CMU 版本的课程也是如此，两者完全一样。作业上只有编程作业，全部基于代码。

在编程作业之后，课程还设置了分组完成的期末项目。讲师在这里先把它列为课程组件，稍后再说明组队方式、工作量和对 Needle 的扩展要求。

第四个组件是课程论坛。这里同样先作预告，后文会具体介绍如何通过论坛提问、互助、组队，以及为何不能公开完整作业解答。

作业通过课程团队自己开发的自动评分系统进行评分。这个系统已经开发了几年，其工作方式可能与我们见过的其他系统有些不同。

关于自动评分系统的具体提交流程，讲师会在本次讲座之后发布一个单独的视频进行演示。这里需要强调的核心区别在于评分系统的设计理念：所有代码都在本地执行，而不是将代码提交到远程的自动评分服务器上运行。

后一种传统做法会引发一系列环境配置问题，因为评分服务器上的运行环境几乎不可能与本地开发环境保持完全一致。本课程采用的是本地执行、仅提交答案的方式。你编写的代码在本地运行并产出结果，然后将这些答案提交给自动评分系统，系统将其与参考答案进行核对。这种机制运行效率更高、速度更快，同时也大幅减少了调试环境配置差异带来的痛苦。

这也意味着，至少在课程录制时，所有操作都可以在 Google Colab 环境中完成。虽然 Colab 经常更新，可能偶尔带来兼容性方面的小摩擦，但整体上可以在其中完成作业编写、代码执行和自动评分提交。关于环境设置以及完成作业的理想工作流程，讲师会在随后发布的单独视频中介绍。

除了独立完成的编程作业之外，课程还设有一个期末项目。与作业不同的是，期末项目以小组形式完成。学生需要在课程论坛上发帖来组建小组，理想的小组规模是三人，尤其对于在线课程而言。如果想组建一人小组或更大的团队，也是允许的。

期末项目的核心要求是为 Needle 框架开发新的功能或能力，其工作量和定位类似“作业五”。作业零用于复习与自我评估，作业一到作业四则是按顺序完成的正式编程作业；期末项目必须进一步扩展 Needle 框架本身。

这一点至关重要：期末项目必须包含对 Needle 库的某种扩展，而不能仅仅实现某种神经网络架构，更不能只在 PyTorch 或 TensorFlow 中实现一个架构后提交。它必须增强 Needle 库本身的能力。

可能的项目方向包括：为后端添加另一种硬件加速方式。课程中的 GPU 部分基于 CUDA，因此可以尝试使用 OpenCL，或针对 Apple M1 芯片进行优化；也可以围绕融合算子开展硬件层面的融合优化。课程后续会发布更多可能的选题，但核心思想始终不变：需要对 Needle 做出扩展。

对于选修这门课的学生，论坛参与同样需要先完成正式注册。注册后很快就会收到加入班级论坛的邀请。论坛应当被视为讨论和交流课程各方面内容的资源平台。

你可以在论坛上寻求帮助，包括作业相关的问题。由于讲师和助教的精力有限，无法回答所有提问，因此课程鼓励学生为那些重要、相关或让自己感到困扰的问题点赞。教学团队会优先回答获得最多点赞的问题，以确保这些不是普遍性的障碍。

同时，课程也希望学生通过回答其他同学的问题来互相帮助，围绕这门课建立一个社区。不要只是发布问题，也去看看自己能否解答别人的疑问。每个人参与得越多，整体受益就越大。

在求助时，发布代码是允许的。论坛的欢迎置顶帖中有进一步的详细说明。虽然有一些正式规则，但实际运作中可以分享少量代码片段。然而，请不要在论坛上原封不动地分享完整的作业解决方案。从这门课中获得的最大收获，来自于自己动手实现作业。如果直接发布完整代码，会让其他人失去这种体验，或者导致他们只是复制代码而非自己编写。在公共论坛上发布内容时请保持合理——你完全可以分享代码片段，但不要试图把完整答案泄露给那些不想看到的人。

课程团队对公开提供这门课程感到非常激动，并期待学生的参与。任何反馈或意见都欢迎提出，虽然在本次开课期间可能无法做出即时更改，但课程之所以公开，就是希望它能成为对深度学习系统感兴趣、或对深度学习整体感兴趣的人的一份资源。如果能提供反馈来帮助改进，以更好地完成这个使命，将不胜感激。

下一堂课的内容会充实得多，将涵盖一些机器学习的基础知识，然后很快进入自动微分的内容。
